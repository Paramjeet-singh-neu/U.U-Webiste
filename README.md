# u.u marketing site

Scroll-driven 3D marketing site for [u.u](https://textuu.ai) (General Intent).

## Phase 1

Scaffold + content only (no 3D). See `PLAN.md`.

```bash
npm install
npm run dev
```

## Stack

Next.js App Router, TypeScript strict, Tailwind CSS v4. Fonts: Schibsted Grotesk (UI / present-you), Newsreader (headlines / future-you).
